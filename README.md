# Week 9 Java Practice Problems

This repository contains five independent Java console programs. Each question has one `Main.java` file and can be compiled and run separately.

## Questions

1. Garden Plot Area Report
2. Weekly Staff Pay
3. Library Late Fine Counter
4. Electricity Connection Billing
5. Travel Booking with a Common Fee

## Requirements

Java 8 or later is required.

## Compile and run

From the repository root, replace `1` with the question number:

```text
javac "QUESTION 1/Main.java"
java -cp "QUESTION 1" Main
```

The program reads the input for that question from standard input and prints the formatted report to standard output.
